# 한국어 지원과 UI 리팩터링

## 사용자 동작

- 설정의 언어 선택에서 한국어와 English를 전환한다. 새로고침 없이 적용하고 기존 `neonDropPreferences` version 2의 `language`에 저장한다.
- 저장한 언어가 없거나 잘못됐으면 브라우저 언어 우선순위에서 첫 지원 언어를 선택한다. 한국어·영어가 모두 없으면 영어를 사용한다.
- 메뉴·HUD·터치 조작·설정·캠페인·결과·순위표·등급·해금 알림·확인창·접근성 문구를 번역한다.
- 기존 모드 ID, 기록 구조, 닉네임, 캠페인 진행도와 게임 규칙은 유지한다. 저장소 쓰기가 차단돼도 현재 세션에서 언어 전환이 동작한다.

## 구조

- `src/js/i18n.js`: 한국어 사전, 언어 결정, 매개변수 치환. 영어 원문을 키로 사용하며 미등록 문구는 원문으로 표시한다.
- `src/js/ui.js`: 명시적인 DOM 번역 키 적용, 동적 문구 적용, 캠페인 설명 생성과 이벤트 표시 번역. 캠페인 설명을 `tetris.js`에서 분리했다.
- `tetris.js`: 언어 변경 시 현재 설정·메뉴·HUD를 갱신한다. 판정에 쓰는 영어 이벤트와 제목은 보존하고 화면에 표시할 때 번역한다.
- 정적 문구에 자식 노드를 보존하는 번역 키를 추가하고, 한국어 시스템 글꼴과 줄바꿈을 지원한다. 새 의존성은 없다.
- 모바일 설정창의 내부 가로 넘침도 수정했다. 텍스트 입력용 최소 너비와 패딩이 체크박스·라디오·슬라이더에 적용되지 않도록 선택자를 좁히고 fieldset의 최소 너비를 해제했다.

## 검증

- 최종 `npm test`: 유닛 147개와 Playwright 브라우저 회귀 33개 함수 전체 통과.
- 언어 우선순위, 저장 언어 보존, 번역 키 누락, 매개변수 일치, 캠페인 설명, 이벤트·등급·해금·조작 안내를 유닛 테스트로 확인했다.
- 한국어 브라우저 첫 실행, 영어/한국어 전환과 재실행 복원, 일시정지 상태 보존, 닉네임 유지, 캠페인·결과·업그레이드 표시, 저장 차단 시 전환을 브라우저에서 확인했다.
- 모바일 설정창에서 `clientWidth: 356`, `scrollWidth: 476`으로 실패하는 테스트를 확인하고 CSS 수정 후 통과했다.
- 1280×900 메뉴와 390×844 메뉴·설정 캡처를 직접 확인했다. 설정은 세로 스크롤을 유지하고 가로 잘림은 해결됐다.
- 변경한 JavaScript 7개 파일의 `node --check`와 `git diff --check` 통과.
- 독립 코드 리뷰와 최종 CSS 리뷰에서 추가 결함 없음.

## 제한

실제 모바일 기기, Safari·Firefox, 배포 환경은 검증하지 않았다. 전체 게임 엔진 분리는 포함하지 않았다. 이전 리뷰 수정은 보존했으며 커밋·푸시는 수행하지 않았다.
