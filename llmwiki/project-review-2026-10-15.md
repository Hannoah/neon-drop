# 2026-10-15 프로젝트 리뷰와 결함 수정

브라우저 단일 플레이 기준으로 게임 루프, 입력, 점수, 보드·회전, AI, 설정·기록 저장, 캠페인, 렌더러와 기존 회귀 테스트를 검토했다.

## 확인하고 수정한 결함

- **ARR 0 통합 오류**: 컨트롤러 자체는 벽까지 반복 이동하지만 `update` 콜백이 이동 성공 여부를 반환하지 않아 실제 게임에서는 한 프레임에 한 칸만 반복했다. 콜백에서 입력 허용 여부와 이동 결과를 반환하도록 수정했다. 기존 브라우저 테스트도 컨트롤러 직접 호출 대신 실제 `update` 경로를 검증한다.
- **잘못된 타이밍 복원**: 누락되거나 숫자로 변환할 수 없는 ARR은 `NaN`이 됐다. 모든 타이밍 값에 유한 숫자 검사를 적용해 기본값으로 복원하고, ARR 0은 유지한다.
- **잘못된 키 바인딩 복원**: 숫자 바인딩은 예외를 일으켜 다른 정상 설정까지 기본값으로 돌아갔고, 문자열 바인딩은 문자별로 분리됐다. 액션별 배열 여부를 검증하고 배열 안의 잘못된 항목을 제거한다.
- **0라인 B2B 보너스 중복 지급**: Marathon에서 B2B 체인 2 이후 0라인 T-Spin에 400점의 체인 보너스가 추가됐다. 라인을 지운 경우에만 해당 보너스를 지급하며 B2B 상태는 유지한다.

## 검증

- 설정 회귀 테스트 2개가 수정 전 `NaN`과 비반복 가능 값 예외로 실패하는 것을 확인했다.
- 브라우저 테스트에서 ARR 0이 x=0 대신 x=3에서 멈추는 것을 확인했다.
- ARR 수정 후 0라인 T-Spin이 400점 대신 800점을 지급하는 것을 확인했다.
- 최종 `npm test`: 유닛 138개 통과, Playwright 브라우저 회귀 32개 함수 전체 통과.
- `node --check tetris.js`, `node --check src/js/settings.js`, `git diff --check` 통과.
